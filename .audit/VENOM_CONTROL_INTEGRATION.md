# تكامل Venom مع أدوات SecurAgentX

## النتيجة

تحولت واجهة Venom من طبقة عرض ذات Terminal محاكى إلى طبقة تحكم محلية مقيدة ذات سجل تدقيق. لا تقبل الطبقة الجديدة نصاً يمر إلى shell، بل تقبل إجراءات مسجلة فقط وتتحقق من هوية جلسة مؤقتة ومن نطاق الهدف قبل التنفيذ. تُرسل Dashboard الإجراء إلى خادم محلي مرتبط بحلقة `127.0.0.1`، وتعرض أمر التنفيذ ومخرجه المنظم في Terminal وفي ترجمة Venom.

| المجال | الربط المضاف | حالة التنفيذ |
|---|---|---|
| Dashboard وVenom | عميل API موحد مع اعتماد جلسة مؤقت محقون في الصفحة المحلية فقط | منفذ ومختبر |
| النطاق | أمر `use target <url>` لا يحدث الهدف النشط قبل تحقق الخادم من المضيف والمنفذ والبروتوكول | منفذ ومختبر |
| الاستطلاع منخفض الأثر | `metadata <url>` و`headers <url>` يعملان على أهداف HTTP(S) المصرح بها فقط، بمهلة وحجم رد مقيدين ومنع إعادة التوجيه | منفذ ومختبر على هدف CTF |
| الحالة والنتائج | أوامر `venom status` و`venom tools` و`venom audit` تسجل النتائج في Terminal | منفذ ومختبر |
| اختبارات المشروع | أمر `run venom tests` يستدعي مجموعة اختبار Venom ثابتة ومحدودة المدة عبر وسيط التنفيذ | منفذ ومختبر |
| الذاكرة والمهارات | أوامر `remember key: note` و`find skill <term>` ترتبط بحالة Dashboard وسجل Terminal | منفذ ومختبر |

## ضوابط الأمان

لا تتضمن قائمة الإجراءات المسجلة أي صدفة حرة أو أدوات تعداد أو تخمين أو استغلال عالية الأثر. ترفض الواجهة أي إجراء غير مسجل وأي عنوان خارج قائمة المضيفين التي يمررها المشغل عند بدء الخادم. كما تمنع إعادة التوجيهات كي لا يستدرج الهدف المصادق الطلب إلى مضيف آخر، وتحتفظ بسجل آخر مئة إجراء فقط. تنحصر الجلسة في `127.0.0.1`، ويُلزم API بترويسة Bearer مؤقتة لا تُخزن في `localStorage`.

> لا يعني ظهور أي أداة ضمن القائمة المرئية القديمة في Dashboard أنها أداة تنفيذية في Venom. الأدوات لا تُربط إلا عند وجود معالج مسجل وسياسة نطاق واختبار انحدار. هذا يمنع عرض نتائج محاكية أو تحويل النص الحر إلى تنفيذ نظام.

## التحقق الحي

تم تحميل الصورة الرمزية Venom وتشغيل الأوامر التالية عبر الواجهة الحية: `venom status`، و`use target`، و`metadata`، و`headers`، و`venom tools`، و`venom audit`، و`remember`، و`run venom tests`. أعاد إجراء metadata من هدف Hacker101 CTF نتيجة HTTP 200 وعنوان `Encrypted Pastebin` وفحصاً بنيوياً محدوداً، وأعاد إجراء headers ترويسات HTTP 200 الحقيقية. كما نفذ أمر اختبار Venom من داخل الواجهة وأعاد نجاح خمس حالات اختبار.

## الاختبارات

نجحت حزمة اختبارات التكامل المركزة: `16 passed`، وتتحقق من قائمة الإجراءات المسجلة، ورفض النطاقات الخارجة، ومنع الأوامر الحرة، وقيود الشبكة، وربط Dashboard، وسلامة الاعتمادات، والذاكرة والمهارات. بدأ تشغيل مجموعة الاختبارات الكاملة للمشروع وتجاوز 80% من الحالات دون إخفاق مرئي، ثم لم يتقدم ضمن مهلات التشغيل المتاحة؛ أوقفت الجلسة المتوقفة بدلاً من إعلان نجاح كامل غير متحقق. يلزم تشغيلها في جلسة منفصلة مع تعريف الاختبار البطيء قبل الاعتماد على نتيجة كلية.

## تشغيل محلي

```bash
python3 -m tools.venom_control_server \
  --port 8765 \
  --allow-target 8340b19dbdf7ed78addd601459980939.ctf.hacker101.com
```

بعد الفتح محلياً، يمكن للمشغل البدء بـ `venom tools` لعرض الإجراءات المسجلة ثم استخدام `use target <url>` قبل أوامر الاستطلاع. لا تُنشئ هذه الخدمة تنفيذاً دائماً ولا تصلح للنشر الخارجي دون طبقة مصادقة وإدارة جلسات مناسبة.
