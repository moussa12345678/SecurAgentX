# جرد سطح تحكم Venom

يكشف الفحص الأولي أن لوحة `dashboard/index.html` تحتوي على قائمة أدوات، وواجهة Terminal، وواجهة Chat، ووحدة SAST، وحالة للنطاق والمهارات والذاكرة والإعدادات. إلا أن طبقة Terminal الحالية لا تشغّل أدوات النظام؛ فهي تضع الأمر في سجل الواجهة ثم تُرجع مخرجات ثابتة لبعض الأوامر، بما في ذلك `scan`.

| السطح | الحالة الحالية | المطلوب لربطه بـ Venom |
|---|---|---|
| التنقل واللوحات | مدعوم داخل الواجهة | توحيد صياغة أوامر Venom وإرجاع تأكيد قابل للتدقيق |
| الحالة والإعدادات | محفوظة في حالة Dashboard | إضافة أوامر قراءة وتغيير محددة الصلاحيات |
| Terminal | محاكاة واجهية | وسيط تنفيذ خلفي محلي بقائمة أدوات ونطاق مصرحين |
| Chat ومزود الذكاء | متصل بـ OpenRouter | فصل الاستدلال عن طلب التنفيذ والتأكيد قبل العمليات عالية الأثر |
| SAST | يعمل في المتصفح على نصوص محددة | ربط تشغيل الفحص وسجل النتائج وحالة التقدم |
| المهارات والذاكرة والنطاق | متاحة في حالة الواجهة | واجهات أوامر قراءة وإدارة منظمة |
| سجل أوامر Python | موجود في `commands/registry.py` ووحدات الأوامر | تكييفه كواجهة تنفيذ موحدة بدلاً من بناء أوامر نصية عامة |
| MCP | مسجل ضمن المشروع | عرض الأدوات فقط وتنفيذ ما تدعمه عقود مصرح بها |

القرار التصميمي المبدئي هو عدم تمرير نص المستخدم إلى shell. سيقبل Venom نوايا منظمة، تتحقق من الهدف والوسيط والسياسة، ثم تستدعي معالجاً مسجلاً أو أداة مصرحاً بها، وتعرض ناتجاً قابلاً للتتبع في Terminal وDashboard.
